## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude API response → UI render | Claude-generated strings (name, ai_focus, hiring_roles) flow through services/claude.py → session state → render loop; all must be html.escaped before reaching markup |
| User selectbox input → prompt | Filter values from fixed-option selectboxes enter the discover_companies() call; no free-text user input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-10 | Tampering (XSS) | company.name rendered in f"**{name}**" via st.write | mitigate | html.escape(company.name) before interpolation — prevents script injection via malicious company name |
| T-02-11 | Tampering (XSS) | company.ai_focus rendered via st.write | mitigate | html.escape(company.ai_focus or "") in render_company_card |
| T-02-12 | Tampering (XSS) | hiring_roles rendered via st.caption | mitigate | html.escape(r) applied to each role in the join expression |
| T-02-13 | Tampering | SAVED_BADGE_HTML with static content | accept | Badge HTML is a hardcoded string constant — no dynamic content; no escaping needed |
| T-02-14 | Denial of Service | discover_running stuck True on exception | mitigate | finally block guarantees discover_running=False even if discover_companies() raises |
| T-02-15 | Tampering | Save button key collision | mitigate | key=f"save_{card_index}_{company.name}" uses index + name — unique per card per render pass |
