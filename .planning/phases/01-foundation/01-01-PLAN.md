<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env file → app | DB_PATH sourced from .env; malformed path could point outside project dir |
| sqlite3 connection | Connection object shared via st.cache_resource; same-thread writes must be serialized |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | database/schema.py — CREATE TABLE statements | mitigate | Use executescript() with literal SQL only; no f-string interpolation in schema init |
| T-01-02 | Information Disclosure | .env file with ANTHROPIC_API_KEY | mitigate | .env in .gitignore; only .env.example committed; plan creates only .env.example |
| T-01-03 | Elevation of Privilege | DB_PATH env var — path traversal | mitigate | Validate DB_PATH is a relative path or within project dir using pathlib.Path.resolve(); reject absolute paths outside cwd |
| T-01-04 | Denial of Service | st.cache_resource on connection | accept | Single-user local app; resource exhaustion not a realistic threat |
| T-01-SC | Tampering | pip install from requirements.txt | mitigate | All packages are well-established (streamlit, anthropic, pandas, pydantic, tenacity, python-dotenv) — no unknown packages; verify checksums with `pip install --require-hashes` if concerned |
</threat_model>
